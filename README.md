# tachimanga-extensions-repo

Personal Tachimanga / Mihon extension repository.

Add this URL in Tachimanga (Browse → Extensions → repositories):

    https://raw.githubusercontent.com/sakanaxd/tachimanga-extensions-repo/main/index.pb

If your app only accepts the older format:

    https://raw.githubusercontent.com/sakanaxd/tachimanga-extensions-repo/main/index.min.json

| Extension | Notes |
|---|---|
| Komga Home | Repackaged [keiyoushi Komga extension](https://github.com/keiyoushi/extensions-source/tree/main/src/all/komga) (Apache-2.0). Spike build: unchanged behaviour. |

Built files only. Server address and credentials are entered in the
extension settings on the device, never stored here.
